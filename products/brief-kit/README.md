# Nexo Brief 1.0

## Espanol

Herramienta de Nexo Digital Partners para preparar el alcance de un proyecto digital. Incluye proyecto, objetivo, publico, alcance, contenido, datos y entrega. El indicador cuenta seis campos esenciales; no evalua la calidad del proyecto.

1. Extrae todo el ZIP y abre `index.html` en un navegador moderno. Conserva la carpeta `assets` junto a los archivos HTML, CSS y JavaScript.
2. Completa tu ficha. Puedes cambiar entre espanol e ingles; esto cambia la interfaz, no traduce tus respuestas.
3. Guarda con el icono de disquete. El guardado es manual y pertenece a ese navegador y dispositivo. En modo privado, o al abrir archivos locales, puede no estar disponible. Usa exportaciones como respaldo.
4. Exporta JSON para editar la ficha despues. Exporta Markdown para compartir un documento de texto. El icono de impresora abre la impresion del navegador, donde puedes elegir PDF.
5. El icono de carpeta importa JSON. Importar reemplaza la ficha visible; exporta antes los cambios que quieras conservar. `example.json` es un ejemplo ficticio, no un cliente ni una cotizacion.

No requiere cuenta, conexion ni suscripcion. No incluye IA, sincronizacion, formularios enviados, seguimiento comercial ni soporte de personalizacion. No transmite las respuestas a Nexo. En la version alojada, el proveedor web recibe las solicitudes normales de la pagina, pero la aplicacion no envia el contenido de la ficha.

No guardes contrasenas, identificaciones, historias clinicas ni datos de otras personas. Los archivos exportados son texto sin cifrar y el almacenamiento del navegador no es una caja fuerte. Borrar los datos del navegador puede eliminar una ficha guardada. Un archivo de otra aplicacion, demasiado grande o con formato incorrecto se rechaza sin sustituir la ficha actual.

Puedes usar esta copia para preparar proyectos personales o comerciales y compartir las fichas que produzcas. No se concede permiso para revender la herramienta o presentar el logotipo como propio. Los iconos Lucide conservan su licencia incluida en `assets/lucide-LICENSE`.

## English

A Nexo Digital Partners tool for defining a digital project's scope. Covers the project, purpose, audience, scope, content, data and delivery. The progress indicator counts six essential fields; it does not assess project quality.

1. Extract the entire ZIP and open `index.html` in a modern browser. Keep the `assets` folder beside the HTML, CSS and JavaScript files.
2. Complete the brief. Switching between Spanish and English changes the interface, not your answers.
3. Use the save icon for manual storage in this browser and device. Private browsing and local-file restrictions may prevent saving. Keep exported backups.
4. Export JSON to edit the brief later, Markdown to share a text document, or use the printer icon and choose your browser's PDF destination.
5. Import JSON with the folder icon. Import replaces the visible brief; export changes you want to keep first. `example.json` is a fictional example, not a client or a quotation.

No account, connection or subscription is required. AI, sync, form submission, sales tracking and customization support are not included. Answers are not transmitted to Nexo. In the hosted version the web host receives normal page requests, but the application does not send brief content.

Do not enter passwords, identity documents, clinical records or other people's personal information. Exported files are unencrypted text and browser storage is not a secure vault. Clearing browser data may erase a saved brief. Invalid, oversized or incompatible files are rejected without replacing the current brief.

You may use this copy for personal or commercial project planning and share the briefs you produce. Reselling this tool or claiming ownership of its brand is not permitted. Lucide icons retain their included license at `assets/lucide-LICENSE`.
